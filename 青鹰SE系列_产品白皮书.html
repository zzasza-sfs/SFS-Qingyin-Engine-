系列总览

青鹰SE系列是针对 SFS 自定义部件体系开发的一级/通用液体发动机家族，采用统一的 1.0 米级安装面与同一设计语言（双色调顶盘、细颈动力段、双侧涡轮泵、锥形钟形喷管）。家族目前包含两款产品：

  • 青鹰SE基准型——可靠、均衡、性价比优先的“标准件”，推力 100 kN / 比冲 290 s / 干重 3.5 t，摆角 ±5°，生涯造价 45。
  • 青鹰SE Pro增压改进型——在同一设计语言下重构了喷管与涡轮泵构造，推力 112 kN / 比冲 311 s / 摆角 ±7°，整机加长加壮，代价是更重、更贵。

两款产品可在同一存档中共存（独立 pack、独立部件名），也可混装于同一枚火箭（如 SE 做助推级、Pro 做芯级）。

第一章　青鹰SE · 产品白皮书

1.1 产品定位

“部署于新一代近地火箭的一级发动机”（原始设计描述）。青鹰SE 是系列基准型：以标准 1.0 米安装口径、均衡的推重比与比冲，覆盖从入门到中级的大部分任务需求。它不追求极端指标，核心价值是稳定、通用、低门槛——相当于整个家族里的“标准主力机型”。

产品版本 1.10 ｜ 包名：青鹰SE.pack ｜ 作者：zzasza ｜ 分类：Basic / Engines

1.2 核心功能与特性

  • 万向摆动 ±5°：喷管随油门联动摆动（MoveModule 旋转曲线 ±5°），提供同尺寸发动机中较宽裕的控制力矩；
  • 全程可节流：推力随油门线性输出，支持精细入轨与悬停调整；
  • 液体燃料（Liquid_Fuel）：与游戏标准燃料体系兼容，消耗按推力/比冲由游戏物理自动计算，无隐藏修正；
  • 一体化造型语言：双色调顶盘 + 细颈动力段 + 双侧内弯涡轮泵 + 锥形钟形喷管，锥形段“上暗下亮”的双色带具有高辨识度；
  • 标准安装接口：顶盘安装面 + 底部喷口对接线，支持上方接油箱、下方挂分离器/次级结构；
  • 完整音效与视觉：点火音效、随油门变化的火焰动画（含光晕层）、热影响区齐全。

1.3 适用场景

  • 近地轨道（LEO）一级动力：100 kN 级推力适合中小型运载火箭的主推进；
  • 通用构型/量产任务：造价低（45），适合在生涯模式中组建标准化火箭家族；
  • 教学与入门：推重比 2.91、比冲 290 s，性能曲线友好，容错高；
  • 需要 ±5° 级控制力矩的重型构型：作为芯级发动机兼顾推力与姿态控制。

1.5 使用与部署指南

安装（部署到游戏）

  • 将 青鹰SE.pack 复制到：
    …\Spaceflight Simulator\Spaceflight Simulator Game\Mods\Custom_Assets\Parts\
  • 启动游戏，部件的“Mod 列表”会出现“青鹰SE”；进入建造模式后，在 Engines / Basic 分类中找到发动机；
  • 无需开启任何作弊选项。

装机要点

  • 顶盘（宽面）朝上，安装面与油箱底面直接对齐即可完成对接（对接线位于顶盘上表面）；
  • 发动机下方可挂分离器（喷口平面留有对接线）；
  • 注意热影响区：喷口正下方近距离布置部件会被尾焰持续加热，长时间点火可能造成损伤。

二次开发（重制/改型）

  • Unity 工程：G:\xiangmuweizhi\Modding Toolkit（Unity 6.1）；源 prefab：Assets/Resources/Parts/Engines/QingYin SE Engine.prefab；
  • 打包脚本：Assets/Editor/QingYinBatchTools.cs；编辑器菜单 SFS ▶ QingYin ▶ Validate Prefab 校验，批处理入口 QingYinBatchTools.ValidateAndBuild；
  • 结构守则：根对象名与关键组件（Part/引擎/扭矩/音频/云台/变量/磁吸/Orientation/CustomSurfaces 及法兰顶面对接线）不可删除或改名，否则会破坏连接与点火行为。

第二章　青鹰SE Pro · 产品白皮书

2.1 产品定位

“青鹰SE 增压改进型一级发动机”。Pro 并非简单放大，而是在保留 SE 设计语言与配色体系的前提下，对喷管构造与涡轮泵构造做了重构的进阶型号：面向追求性能上限的进阶玩家与高 Δv 任务，是家族的“高性能定制款”。

产品版本 1.0 ｜ 包名：青鹰SEPro.pack ｜ 作者：zzasza ｜ 分类：Basic / Engines ｜ 支持图标显示

2.2 核心功能与特性（相对 SE 的升级点与构造差异）

性能升级（同一燃料、同一物理规则）

  • 推力 100 → 112 kN（+12%）：更强的起飞段加速能力；
  • 真空比冲 290 → 311 s（+7.2%）：更高效率的真空段表现；
  • 万向摆角 ±5° → ±7°（+40%）：家族标志性的“控制力升级点”，大幅提升重型构型的姿态控制余量；
  • 推重比小幅提升（2.91 → 3.00，+3.1%）：干重虽增至 3.8 t，但推力增幅更大。

构造重构（“同风格、异构造”）

  • 两件式喷管：本体喷管（喉部+上段锥体）+ 独立加装式延伸裙；通过套筒搭接 + 深色联轴环咬合，接口在轮廓上清晰可辨——与 SE 的一体式喷管形成明确的结构差异；
  • 两段式涡轮泵：细进气管 + 内弯肘管（下段），台阶过渡后接粗泵体（上段），不同于 SE 的等径直管；
  • 钟形段加长（喷口自 -2.06 延至 -2.48）：更高的等效膨胀比表现，整体轮廓更修长；
  • 升级音效：更低沉的点火/运行声底（Engine_Pro，音高 0.17 → 0.155）；
  • 配色与 SE 完全同源：同一套材质与色带（Metal / Metal_4 / Color_White + 同色阶），两代产品并排装机风格统一。

权衡与注意（合理瑕疵）

  • 更重：干重 +8.6%（3.5 → 3.8 t）；
  • 更高：总长 +20%（2.06 → 2.48），紧凑构型需预留空间；
  • 更贵：生涯造价 +55.6%（45 → 70）；
  • 热影响区更大：高室压设计伴随更强势的尾焰热区，喷口下方部件受热更快。

2.3 适用场景

  • 高 Δv 上面级 / 深空任务：311 s 比冲带来更高的任务余量；
  • 重型构型与精确入轨：±7° 摆角显著增强大长径比火箭的姿态控制；
  • 进阶玩家的性能构型：愿意用造价和长度换取推力的场景；
  • 与 SE 混编：Monorepo 式家族搭配——SE 做助推/近地主力，Pro 做芯级/上面级。

2.5 使用与部署指南

安装（部署到游戏）

  • 将 青鹰SEPro.pack 复制到：
    …\Mods\Custom_Assets\Parts\（与青鹰SE 放同一目录，互不冲突）；
  • 游戏模组列表显示“青鹰SE Pro”，建造模式 Engines / Basic 分类取用；
  • 开启/不开启作弊模式行为一致（自热保护机制已配置）。

装机要点

  • 顶盘对接线与 SE 完全同款（顶盘上表面），上方油箱直接对接；
  • 喷口平面（-2.48）留有下方对接线，可挂分离器；
  • 两件式喷管的联轴环为深色带，属设计特征而非贴图错误；
  • 热区较 SE 更大，喷口下方布置部件需留出更长的安全距离。

二次开发与重新导出

  • 源 prefab：Assets/Resources/Parts/Engines/QingYin Pro Engine.prefab（独立 prefab，非变体）；Unity 工程同上；
  • 在 Unity 中修改模型后，使用菜单 SFS ▶ QingYin Pro ▶ Export Current Prefab as Pack 一键重新打包并自动部署（该通道不会覆盖手动改动，并会自动执行结构校验：必需模块、油箱对接线、喷口对接线、自热豁免、脚本完整性）；
  • 改名警示：prefab 根对象名（QingYin Pro Engine）被存档引用，请勿修改；修改子部件名称/位置/材质均安全。
